Pengembangan & Pengamanan Ekosistem Aplikasi Enterprise di PT PAL Indonesia

Studi kasus komprehensif mengenai perancangan sistem absensi vendor (Subkon), refactoring & penguatan keamanan sistem dokumen enkripsi (Simandok), serta integrasi sistem internal perusahaan galangan kapal BUMN.

Ringkasan Eksekutif (Executive Summary)

Sebagai Pemrogram Komputer Contract di PT PAL Indonesia (Badan Usaha Milik Negara industri pertahanan & maritim terkemuka), saya bertanggung jawab merancang, mengoptimalkan, dan mengamankan berbagai sistem informasi enterprise secara end-to-end. Fokus utama meliputi pembangunan Website Subkon dari tahap arsitektur skema database hingga deployment server, refactoring codebase Website Simandok untuk perlindungan dokumen rahasia, serta pengujian berkala terhadap modul absensi makan siang (Siamang) dan lelang tender (Ebidding).

1. Latar Belakang & Kebutuhan Bisnis

PT PAL Indonesia mengelola ribuan tenaga kerja eksternal (subkontraktor/vendor) dan ribuan dokumen teknik perkapalan yang berstatus sangat rahasia. Sebelum modernisasi sistem dilakukan, beberapa tantangan operasional yang dihadapi antara lain:

  • Validasi Absensi Vendor Manual: Kompleksitas pencatatan kehadiran personel subkontraktor di area galangan kapal yang luas memerlukan sistem terpusat yang presisi untuk mencegah kecurangan dan mempercepat rekonsiliasi penagihan bulanan.
  • Keamanan Dokumen Manufaktur: Dokumen desain blueprint kapal militer dan niaga membutuhkan mekanisme enkripsi tingkat tinggi dan audit log yang ketat agar tidak bocor ke pihak luar.
  • Integrasi Antar Layanan Internal: Perlunya sinkronisasi data identitas pekerja, fasilitas makan siang di galangan, serta sistem lelang barang/jasa vendor yang terhubung harmonis.

2. Rincian Sistem yang Dikembangkan

Berikut adalah 4 aplikasi web enterprise utama yang menjadi tanggung jawab saya dalam perancangan, pengembangan, dan pengujian:

Website Siamang

Sistem Absensi Makan Siang

Sistem otomasi pencatatan dan verifikasi kehadiran karyawan untuk fasilitas konsumsi makan siang di galangan kapal.

  • Mengembangkan dan mengoptimalkan sistem absensi dengan membenahi bug/error serta menambahkan fitur-fitur baru.
  • Membantu proses deployment website ke server.
  • Menyusun dokumentasi sistem secara komprehensif, mulai dari User Acceptance Test (UAT) hingga Manual Book/Panduan Pengguna.
PHP MySQL Bug Fixing Server Deployment UAT & Manual Book

Website Simandok

Sistem Management Document

Aplikasi sentralisasi penyimpanan dan sirkulasi dokumen teknis serta manajerial enterprise yang membutuhkan proteksi ketat.

  • Melakukan refactoring codebase ke versi framework terbaru untuk meningkatkan performa, maintainability, dan skalabilitas sistem.
  • Menerapkan security hardening pada aplikasi web untuk meminimalisir celah kerentanan dan melindungi data enterprise.
  • Menyusun dokumentasi teknis dan operasional secara lengkap, mencakup UAT serta panduan penggunaan aplikasi.
Framework Refactoring Security Hardening UAT Documentation Enterprise Data

Website Ebidding

Website Lelang Tender

Portal pengadaan barang dan lelang terbuka untuk memfasilitasi vendor eksternal secara transparan dan akuntabel.

  • Mendukung pengembangan website untuk memfasilitasi vendor dalam mengikuti proses lelang tender.
  • Melakukan pengujian (testing) secara menyeluruh untuk mengidentifikasi, menganalisis, dan memperbaiki bug demi menjaga stabilitas sistem.
  • Menyusun dokumen User Acceptance Testing (UAT) serta membuat video tutorial penggunaan website bagi vendor.
E-Procurement System Testing UAT Video Tutorial

Website Subkon

Website Absensi Vendor

Sistem absensi dan tata kelola tenaga kerja subkontraktor secara menyeluruh dari perancangan hingga implementasi server.

  • Mengembangkan website absensi vendor secara end-to-end, mulai dari perancangan skema database hingga implementasi penuh sistem.
  • Melakukan pengujian (testing) secara menyeluruh untuk mengidentifikasi, menganalisis, dan memperbaiki bug demi menjaga stabilitas sistem.
  • Mengembangkan dan mengimplementasikan fitur inti, meliputi User Management System, manajemen data karyawan vendor, serta sistem absensi berbasis web hingga proses deployment ke server perusahaan.
End-to-End Dev Database Schema User Management Server Deployment

5. Pembelajaran Utama (Key Takeaways)

Bekerja di lingkungan industri manufaktur strategis seperti PT PAL Indonesia memberikan pengalaman berharga tentang bagaimana software engineering harus selaras dengan prosedur ketat (SOP), kepatuhan standar keamanan data (cyber security standards), dan keandalan sistem jangka panjang.
