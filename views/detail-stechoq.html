Project: Website Management System for Mobile Phone Warehouse – PT Stechoq Robotika Indonesia

Perancangan dan pembangunan arsitektur backend RESTful API untuk sistem manajemen gudang retail handphone menggunakan Node.js, Express Js, dan MySQL.

Ringkasan Proyek (Berdasarkan CV Resmi)

  • Mengembangkan website untuk manajemen gudang handphone, termasuk pencatatan stok masuk dan keluar.
  • Merancang dan membangun API RESTful untuk pengelolaan produk, supplier, dan transaksi gudang.
  • Bertanggung jawab pada sisi backend, termasuk autentikasi pengguna, manajemen database, dan dokumentasi API.

1. Latar Belakang & Tantangan Pergudangan Retail

Industri retail smartphone memiliki dinamika persediaan yang sangat cepat dengan nilai barang (unit price) yang tinggi. Setiap unit memiliki nomor seri unik (IMEI/Serial Number) yang wajib terlacak akurat. Kendala umum yang dihadapi retail meliputi:

  • Discrepancy Selisih Stok Antar Cabang: Terjadinya selisih antara stok tercatat di komputer dengan stok fisik di rak gudang akibat proses mutasi barang antar outlet yang lambat dicatat.
  • Ketiadaan Peringatan Stok Rendah (Out of Stock Risk): Hilangnya potensi penjualan produk best-seller karena keterlambatan pengadaan ulang barang dari pihak prinsipal atau distributor.
  • Audit Trail yang Lemah: Kesulitan melacak staf mana yang mengotorisasi pengeluaran barang jika terjadi kehilangan unit bernilai tinggi.

2. Arsitektur Backend & Endpoint Utama

Backend API dibangun dengan arsitektur berlapis (Controller-Service-Repository Pattern) menggunakan Node.js dan Express.js untuk memastikan kode bersih, mudah di-maintain, dan scalable:

Autentikasi & RBAC JWT Terproteksi

Keamanan & Hak Akses Berjenjang

Implementasi token JSON Web Token (JWT) dengan refresh token rotation dan middleware otorisasi berbasis peran (Role-Based Access Control).

  • Pembagian peran jelas: Superadmin, Manajer Gudang, Staff Input, dan Kasir Toko.
  • Enkripsi password menggunakan bcrypt dengan cost-factor aman.
  • Blacklisting token saat user logout untuk mencegah replay attack.
JWT Bcrypt RBAC

Multi-Location Inventory Tracking

Manajemen Stok & Mutasi Real-time

Pencatatan persediaan di gudang pusat, gudang transit, dan masing-masing gerai cabang secara sinkron dalam satu basis data terpadu.

  • ACID Transactions MySQL untuk menjamin integritas data mutasi stok.
  • Validasi stok sebelum transaksi pengeluaran (mencegah minus stock concurrency).
  • Pelacakan riwayat pergerakan unik setiap unit berdasarkan IMEI handphone.
Node.js Express.js MySQL ACID

Automated Reorder Threshold

Pemicu Peringatan Stok Kritis

Algoritma pengecekan stok otomatis yang memberikan status peringatan dini saat persediaan produk mencapai batas minimum pemesanan ulang.

  • Perhitungan lead time dan minimum buffer stock per kategori varian produk.
  • Endpoint laporan otomatis produk prioritas restock untuk tim Purchasing.
  • Penyaringan laporan berdasarkan vendor, merek handphone, dan lokasi cabang.
Business Logic Analytics Reporting

Swagger OpenAPI & Automated Testing

Dokumentasi Interaktif & QA Jest

Memudahkan kolaborasi dengan tim frontend dan mobile melalui dokumentasi interaktif Swagger UI serta automated unit/integration test.

  • Swagger UI interaktif yang memungkinkan tim developer mencoba request langsung.
  • Pengujian skenario endpoint menggunakan Jest dan Supertest (Happy & Error Path).
  • Koleksi Postman terstruktur lengkap dengan environment variables otomatis.
